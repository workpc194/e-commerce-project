# 🛒 NexMall - Modern E-Commerce Web Application

NexMall is a sleek, responsive, and feature-rich e-commerce web application designed to deliver an intuitive and seamless shopping experience. Inspired by modern storefront designs, NexMall features dynamic product catalogs, seamless category navigation, interactive cart management, and interactive showcase elements.

## ✨ Key Features & Functionality

### 🛍️ Dynamic Product Catalog
- **Live Data Fetching:** Integrates with the **DummyJSON API** to load real-time product data, pricing, stock levels, ratings, and image galleries.
- **Category Filtering:** Browse items seamlessly across diverse categories including electronics, fashion, home decor, and personal care.
- **Search & Filter:** Find products quickly using instantly updating search bars and multi-criteria filters.

### 🔍 Interactive Product Details Page
- **High-Resolution Image Gallery:** Toggle between various product thumbnail images and view detailed product close-ups.
- **Comprehensive Metadata:** Displays brand details, product ratings, stock availability, customer reviews, and discount tags.
- **Quantity Selector:** Adjust item quantities before adding them to your cart.

### 🛒 Real-Time Shopping Cart
- **Dynamic Cart Management:** Add items, modify quantities, and remove products on the fly with immediate price recalculations.
- **Order Summary:** Displays item subtotal, applicable taxes, shipping fees, and final checkout prices transparently.
- **Persistent State:** Saves user cart selections locally to maintain session state even after refreshing the page.

### 📱 Responsive & Intuitive Design
- **Mobile-First Layout:** Fully optimized for smartphones, tablets, and desktop displays.
- **Modern UI Elements:** Clean navigation bar, attractive hero slider, polished product cards, and sleek hover animations inspired by *ShopHub*.
- **Fast Performance:** Deployed on Vercel for fast loading speeds, optimized asset fetching, and continuous delivery.
